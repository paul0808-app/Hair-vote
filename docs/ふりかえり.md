# ヘアスタイル投票アプリ ふりかえり

開発未経験・iPadのみという条件で、Claude Code を使って約3週間（実作業は数日）で
完成させた記録です。**次に何かを作るときの手引き**としてまとめています。

---

## 1. 何を作ったか

美容室4店舗（PAUL / COコ / 行徳 / Ali&LEVEL・全25席）の各席タブレットで、
お客様がヘアスタイル写真に「いいね」して投票するアプリ。

- お客様は写真を最大5枚選んで投票する
- スタッフは管理画面でランキングを見て、写真を登録・管理する
- コンテストの表彰3種（スタイル別・スタイリスト別・店舗賞）を自動集計する

**公開URL**

| 用途 | URL |
|---|---|
| 投票画面 | `https://hair-vote.vercel.app/` |
| 管理画面 | `https://hair-vote.vercel.app/admin?key=合言葉` |

## 2. 技術構成と、それぞれの役割

| サービス | 役割 | ふだん開くか |
|---|---|---|
| **GitHub** | コードの置き場所 | 開かない |
| **Vercel** | アプリを公開する仕組み | 初期設定だけ |
| **Supabase** | データの保管庫（投票・写真） | 初期設定だけ |
| **hair-vote.vercel.app** | 実際のアプリ | **毎日ここだけ** |

この4つの区別がつくまでが、いちばん混乱しやすいところでした。
**設定するサイト（Vercel / Supabase）と、使うサイト（アプリ本体）は別物**です。

使った技術：Next.js（App Router）+ TypeScript + Tailwind CSS + Supabase(PostgreSQL)

---

## 3. 進め方（フェーズ分け）

いちどに全部作らず、5つに分けて、**1つ終わるごとに動作確認**しました。

| フェーズ | 内容 |
|---|---|
| 1 | 投票画面の見た目（仮の写真30枚） |
| 2 | 拡大モーダル・投票確定・完了画面 |
| 3 | Supabase接続（投票の保存） |
| 4 | 管理画面（ランキング・CSV・写真管理） |
| 5 | ホーム画面への追加（PWA）・運用の仕上げ |

**これが最大の成功要因でした。** 一気に作ると、どこが壊れているか分からなくなります。
フェーズごとに「iPadで何を触れば確認できるか」を箇条書きでもらい、
実際に触ってから次へ進みました。

完成後も、使いながら11回の改良を重ねています（リセット機能、2回タップ選択、
並び順ランダム、写真の削除、表彰の集計など）。
**「完成」してからが本番**で、実際に使うと必ず要望が出てきます。

## 4. つまずいた点と、その原因

次回同じ所で止まらないための記録です。

### 4-1. Vercelにデプロイしたのに404になった

**原因**：アプリのコードが `main` ブランチに無かった。Vercelは既定で `main` を公開する。

**教訓**：作業用ブランチで開発していても、**公開されるのは `main`**。
ビルドが「Ready」でも、中身が空なら404になる。

### 4-2. 環境変数を設定したのに反映されない

**原因**：Vercelの環境変数は、**設定しただけでは反映されない**。

**教訓**：環境変数を足したら必ず **Deployments → … → Redeploy**。これを忘れると何も変わらない。

### 4-3. SQLの「URL」を貼ってしまった

**原因**：「このURLのSQLを実行して」と言われ、URLそのものをSQL入力欄に貼った。

**教訓**：URLは**置き場所の住所**。必要なのは**中身の文字**。
Safariでそのアドレスを開いて、表示された文字を全選択→コピーして貼る。
（Claudeには「SQLをチャットに直接貼って」とお願いするのが確実）

### 4-4. 秘密のキーの種類を間違えた

**原因**：Supabaseのキーには2種類ある。

| | publishable / anon | secret / service_role |
|---|---|---|
| 性格 | 公開してよい | **絶対に公開しない** |
| 今回必要なのは | ✗ | **○** |

このアプリはブラウザから直接データベースを触らせない設計（RLSを有効にして
許可ルールを作らない）なので、publishable では1枚も写真が読めません。

### 4-5. Supabaseのプロジェクトが勝手に停止した

**原因**：無料プランは**1週間ほどアクセスが無いと自動で一時停止**する。

**対処**：Resume project を押せば復帰（データは消えない）。
再発防止として、1日1回アプリが自分でデータベースに触る仕組み
（`/api/keep-alive` + Vercelの定期実行）を入れた。

### 4-6. 写真が表示されないまま固まった ← 本当のバグ

**原因**：画像の読み込みがページの初期化より先に終わると、
完了の合図をアプリが受け取れず、写真があるのに表示されない状態になっていた。

**教訓**：「遅い」と感じたら、**回線のせいと決めつけない**。
実際にはコードの不具合だった。**症状を具体的に伝える**と原因にたどり着きやすい。

### 4-7. 管理画面をホーム画面に追加したら投票画面が開いた

**原因**：「ホーム画面に追加」の設定に、起動URLとして投票画面が書かれていた。

**対処**：管理画面ではその設定を読み込まないようにした。

### 4-8. サンプル画像が遅かった

**原因**：最初に入れたサンプル写真は外部の無料サービス（picsum.photos）配信で、
海外から届くため遅い。

**教訓**：**サンプルデータは「動作確認用」であって、そのまま使うものではない**。
実際の写真を入れれば速くなる（Supabase Storageの東京リージョンから配信される）。

## 5. Claude Code に頼むときのコツ

実際にうまくいった頼み方です。

### 最初に伝えるとよいこと

- **自分の前提**（例：開発未経験、iPadしかない、PCは使えない）
- **やらないこと**も明記する（例：ログイン機能は作らない）
- **フェーズに分けて、1つずつ止まって確認させる**

この3つを最初の指示に入れたのが効きました。

### 詰まったときの伝え方

| よくない | よい |
|---|---|
| 「動かない」 | 「この画面のこのボタンを押したらこのエラーが出た」 |
| 「遅い」 | 「写真が出ない。10秒待っても灰色のまま」 |
| 「わからない」 | **画面のスクリーンショットを送る** |

**スクリーンショットがいちばん速い**です。画面名やボタンの位置まで正確に案内が返ってきます。

### 判断に迷ったら聞いてよい

「スタイリストはプルダウンにした方がいい？」のように**設計を相談**すると、
理由つきで答えが返ってきます。実際この質問から、表記ゆれ対策と
店舗賞の分母の設計が決まりました。

### 安全に関わることは必ず確認する

- 秘密のキーはチャットに貼らない（Vercelに直接貼る）
- 「削除」機能は、取り消せるかどうかを必ず確認する
  （今回、集計リセットは「データを消さず開始点を記録する」方式にして取り消せるようにした）

## 6. 設計で効いた判断

技術的な話ですが、同じような仕組みを作るときの参考に。

| 判断 | 理由 |
|---|---|
| **いいねを押すたびに保存しない** | 投票確定の1回だけ保存。25席が同時に使っても競合しない |
| **票数は毎回数える（カウンターを持たない）** | 「+1する」方式は同時更新でズレる |
| **同じ投票の二重登録をデータベース側で防ぐ** | 画面側の制御だけを信用しない |
| **集計リセットはデータを消さない** | 「ここから数える」開始点を記録。押し間違えても戻せる |
| **スタイリストは名簿から選ぶ** | 手入力だと表記ゆれで別人として集計される |
| **店舗賞の分母は名簿の人数** | 誰を登録するかで分母を自分で決められる |
| **つながらないときも画面を止めない** | 仮データや案内を出して、真っ白にしない |

## 7. 運用メモ

### 毎日の運用
- タブレットはホーム画面のアイコンから開く（全画面になる）
- 1人終わるごとに完了画面の「次のお客様へ」を1タップ
- 投票確定から30分で自動的に次の投票を受け付ける

### ときどきやること
- 管理画面で**並び順をランダムにする**（上にある写真に票が偏るのを防ぐ）
- ランキングを見る・CSVをダウンロードする
- コンテストが終わったら**集計をリセット**（取り消し可能）

### 写真を入れ替えるとき
- 管理画面 →「写真の管理」→ 写真を選んで登録（自動で縮小される）
- 古い写真は「非表示」（票は残る）か「削除」（票も消える）

### 困ったときの確認順
1. 投票画面の下に「（仮データ）」と出ていないか → 出ていればデータベース未接続
2. Supabaseが一時停止していないか → Resume project
3. Vercelの環境変数を変えたあと、Redeployしたか
