# ヘアスタイル投票アプリ（Hair-vote）

美容室（PAUL西葛西店・COコ西葛西南口店）の各席のタブレットで、
お客様が好きなヘアスタイル写真に「いいね」して投票するアプリです。

## フェーズ1でできること

- ヘアスタイル写真を格子状（グリッド）に並べて表示
  - iPad 横向き（1024px〜）＝ **5列**
  - iPad 縦向き・中間サイズ（640〜1023px）＝ **4列**
  - スマホ（〜639px）＝ **3列**
- 写真をタップすると選択される（もう一度タップで解除）
- 選択された写真は、**太いピンクの枠線・右上の番号バッジ・薄い暗色・チェックマーク**の4つが同時に付く
- 最大5枚まで。6枚目を押すと「最大5枚までです」というお知らせが2秒だけ出る
- 画面下に固定バー。`2枚 / 5枚 選択中`とドット（●●○○○）を表示。0枚のときは「投票へ進む」が押せない
- 5枚そろうとバーの色が変わって「選択完了！」になる
- 選んだ内容はブラウザに保存されるので、画面を閉じても開き直せば選択が残る

**まだできないこと（フェーズ2以降）**
写真の拡大表示、投票の確定、完了画面、管理画面。
いまは「投票へ進む」を押してもお知らせが出るだけです。

**写真について**
いまは仮の写真（picsum.photos というサンプル画像サービス）を使っています。
実際のヘアスタイル写真はフェーズ4の管理画面から登録できるようにします。

## iPad だけでの公開手順（初回だけ・所要10分ほど）

PCは不要です。iPad の Safari だけで完了します。

### 1. Vercel にログインする

1. Safari で **https://vercel.com** を開く
2. 右上の **「Sign Up」**（または Log In）→ **「Continue with GitHub」** を選ぶ
3. GitHub のアカウントでログインし、Vercel からのアクセスを許可する

### 2. このリポジトリを取り込む

1. ログイン後の **Dashboard**（最初に出る一覧画面）で **「Add New...」→「Project」** を押す
2. **「Import Git Repository」** の一覧から **`Hair-vote`** を探して **「Import」** を押す
   - 一覧に出ないときは、その下の **「Adjust GitHub App Permissions」** から `Hair-vote` を許可する
3. **Framework Preset** が **Next.js** になっていることを確認（自動で入ります）
4. 設定は何も変えずに **「Deploy」** を押す

### 3. できあがったURLを開く

- 1〜2分待つと「Congratulations」の画面になります
- 表示された **`https://hair-vote-〇〇〇.vercel.app`** のURLが投票画面です
- このURLをタブレットの Safari で開いてください

### 4. 開発中のブランチを見るには

いまの作業は `main` ではなく **`claude/hairstyle-voting-app-5w5suj`** というブランチにあります。

- Vercel の Dashboard → プロジェクト名 → 上部の **「Deployments」** タブを開く
- ブランチ名が `claude/hairstyle-voting-app-5w5suj` の行をタップ
- **「Visit」** ボタンでプレビューURLが開きます（このURLで今の画面を確認できます）

> 以降は、このリポジトリに変更を push するたびに Vercel が自動でURLを更新します。
> 何も操作は要りません。

## フェーズ1の動作確認チェックリスト（iPadで操作してください）

上のプレビューURLを iPad の Safari で開いて、次を確認してください。

- [ ] 写真が格子状に並んでいる（**iPadを横向き**にすると5列、**縦向き**にすると4列になる）
- [ ] 写真は正方形に切り取られて表示されている
- [ ] 下にスクロールすると30枚すべて見られる
- [ ] 写真を1枚タップすると、**ピンクの太枠・右上に「1」のバッジ・少し暗くなる・左下にチェック**が付く
- [ ] もう一度同じ写真をタップすると選択が解除される
- [ ] 3枚選ぶと、下のバーが `3枚 / 5枚 選択中` になり、ドットが●●●○○になる
- [ ] 5枚選ぶと、下のバーが**ピンク色**に変わり「選択完了！」と出る
- [ ] 6枚目をタップすると「最大5枚までです。他の選択を解除してください」が2秒だけ出る
- [ ] 1枚も選んでいないとき、「投票へ進む」ボタンがグレーで押せない
- [ ] 数枚選んだ状態で Safari を閉じて開き直すと、**選択が残っている**
- [ ] 画面をいちばん下までスクロールしても、下のバーが写真に重なって邪魔していない

うまくいかない点があれば、**どの項目か番号や文言で教えてください**。

## 技術メモ（開発者向け）

- Next.js 16（App Router）+ TypeScript + Tailwind CSS v4
- 選択状態は React の state と `localStorage` のみで管理し、**データベースには書き込まない**
  （投票確定時に1回だけ書き込む設計。フェーズ3で実装）

```
app/
  layout.tsx        全ページ共通の枠組み
  page.tsx          投票画面（トップ）
  globals.css       共通スタイル・配色
components/
  vote-screen.tsx   投票画面の本体
  style-card.tsx    写真1枚のカード
  bottom-bar.tsx    画面下の固定バー
  toast.tsx         2秒で消えるお知らせ
lib/
  types.ts          データの形の定義
  dummy-styles.ts   仮の写真データ30件（フェーズ3で差し替え）
  use-selection.ts  選択状態の管理と localStorage 保存
```
